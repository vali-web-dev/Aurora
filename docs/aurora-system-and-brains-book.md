# Aurora System and Brains Book

A comprehensive, navigable manual for Aurora in two editions:
- End-User Help Manual (free)
- Developer Manual (paid)

This book is designed for publication and in-app help use. It aggregates and organizes all Aurora documentation into a structured, multi-file book with full cross-links.

## How To Use This Book
- Start with the appropriate edition index below.
- Use the table of contents and per-universe chapters to navigate.
- Each chapter links to related system chapters and reference appendices.
