# Human Blueprint Visual Style Guide

## Color System

- **Deep Space Black**: `slate-950` / `slate-900`
- **Aurora Blue**: `blue-500..700` and `cyan-500..700`
- **Celestial Gold**: `amber-400..600`
- **Soft White**: `slate-50` / `white`
- **Organ category accents**
  - Organ: red/cyan/amber/violet family
  - System: blue/emerald family
  - Feature: gold/sky family

## Typography

- **Headings**: existing Aurora display style (`aurora-label` with semibold/strong hierarchy)
- **Body text**: existing Aurora readable body styling (`aurora-label`, high-contrast slate ramps)

## Components

- Panels: Card + modal-based layered insight panel
- Cards: Summary, Daily Focus, Timeline
- Tabs: Phase selector buttons (P1..P5)
- Accordions (planned): scaffolded for layer expansion in split-view panel
- Tooltips (planned): contextual mesh guidance
- Progress indicators: explored/mastered badges + timeline
- Daily focus widget: one organ/system per day with micro-action

## Motion

- Breathing oscillation on core model group
- Cardiac pulse animation on heart mesh
- Smooth front/back camera transitions
- Soft emissive hover and selection glow

## Layout

- Minimal spacious card system
- Large 3D viewport centered as primary interaction
- Progressive information disclosure by phase
- Gentle continuity signals (last visit, timeline, mastery)

## Accessibility

- Keyboard-clickable quick links
- Semantic list labels on quick-link clusters
- Modal focus trapping and close on escape
- High-contrast text in dark/light modes
