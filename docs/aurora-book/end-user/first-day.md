# Your First Day in Aurora

This is a guided first session designed to help you feel the system quickly without overload.

## Step 1: Pick Your Time
Start in Home and select your time and energy level:
- Morning
- Midday
- Evening
- Night

Aurora adjusts its tone based on time and energy.

## Step 1.5: Check Your Defaults
- Memory is off by default
- Suggestions are off by default
- Sync is off by default
- You can enable any of these later

## Step 2: Explore One Universe
Choose one universe and spend 10-15 minutes:
- Learning if you want growth
- Create if you want to build
- Productivity if you want structure
- Social if you want connection
- Entertainment if you want rest

## Step 3: Meet Your Companion
Open the Companion Panel (CP) to see:
- Current tone and scope
- Current universe
- A short hint about how Aurora is thinking

## Step 4: Customize Your Theme
Open the theme selector and choose:
- Light or Dark
- Theme family (Home, Office, Outdoor, Lifestyle, Creative)

If you prefer motion-free UI, enable reduced motion in your system settings.

## Step 5: Create Something Small
In Create, make something tiny and save it. It stays local unless you share it.

## Step 6: Turn On Memory (Optional)
In the Companion Panel, enable memory if you want Aurora to remember context.

If you skip this step, Aurora still works fully, it just will not retain context between sessions.

## Step 7: Set a Signal
Try a signal such as Focus or Exploration and observe how the tone shifts.

## Step 8: Take a Break
Close the app and return later. Aurora should remember your theme and, if enabled, your memory.

## Step 9: Try One Power Feature
- Set a Focus signal and start a task session
- Join a community event
- Build a watchlist in Entertainment

## Step 10: Save Your Preferences
Visit Settings and confirm:
- Theme mode and family
- Accessibility preferences
- Notification defaults

## What Good Looks Like After Day One
- You can move between universes quickly
- You know where Companion Panel lives
- Your theme is set and feels right
- You completed one small task or creation

## If Something Feels Off
- Use Settings to reduce motion or increase contrast
- Clear memory in the Companion Panel
- Switch universe to reset context
