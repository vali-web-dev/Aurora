# Glossary

- Universe: A dedicated digital world inside Aurora (Home, Learning, Create, etc.)
- Companion: The adaptive personality system
- Tone: The companion communication style
- Scope: The memory and tool range for the companion
- Signal: A user-selected mode that shapes tone and scope
- Theme family: A color family applied across the UI
- Local-first: Data stored on your device by default
- Sync: Optional encrypted backup across devices
- Memory: The set of context and preferences Aurora can store
- Suggestions: Optional guidance surfaced by Aurora
- Illuminated mode: Aurora signature visual theme with glow and color
- Accessibility mode: A set of settings for contrast, motion, and text size
- Surface: A primary content area in a universe
- Companion Panel: The CP menu for tone, scope, and memory controls
