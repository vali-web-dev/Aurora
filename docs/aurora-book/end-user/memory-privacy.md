# Memory, Privacy, and Consent

Aurora is local-first. Memory is off by default, and you control every data decision.

## What Aurora Remembers
Automatic (unless disabled):
- Universes visited and timestamps
- Visit counts
- General time patterns

With permission:
- Notes in Companion Panel
- Goals and projects
- Learning progress and bookmarks
- Saved searches and filters

Never by design:
- Passwords or payment data (outside encrypted vault)
- Private messages (unless explicitly shared)
- Health data unless you export
- Entertainment consumption history unless bookmarked

## Storage Model
- Local storage and IndexedDB by default
- Optional encrypted sync if you opt in

## Memory Levels and Scope
- Minimal: no memory, no suggestions
- Light: basic memory, no suggestions
- Standard: memory on, occasional suggestions
- Deep: memory and insights
- Intensive: full tools and export

## Control and Deletion
- Clear individual items
- Clear a universe
- Clear all memory

## Transparency
- You can view recent memory in the Companion Panel
- You can clear or edit memory items at any time

## Privacy Rights
- Access: Export your data
- Deletion: Remove local and synced data
- Portability: Standard formats
- Explanation: Understand why suggestions appear
- Control: Disable memory, suggestions, or sync

## Consent Defaults
- Memory off by default
- Suggestions off by default
- Sync off by default
- Experimental features off by default

## Data Export
- Export your data in standard formats
- Use exports for backups or migration
