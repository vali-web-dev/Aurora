# Companion System (End User)

Aurora is not a chatbot. It is a personality engine that adapts to your universe, signals, and time patterns.

## How It Works
1. Universe detection sets a default tone.
2. Signals can override the default tone.
3. Scope controls how much memory and tooling are active.

## Tones
- Mentor: Warm, encouraging, example-rich
- Strategist: Direct, goal-focused
- Explorer: Curious and discovery-led
- Analyst: Neutral and data-driven
- Guardian: Protective and safety-first

## Scopes
- Minimal: No memory, no suggestions
- Light: Basic memory, no suggestions
- Standard: Memory on, occasional suggestions
- Deep: Memory and insights
- Intensive: Full tools and export

## Signals
- Exploration, Focus, Learning, Creation, Relaxation, Crisis, Collaboration, Reflection

## Companion Panel
Open CP to see:
- Current tone and scope
- Current universe and context snapshot
- Memory controls
- Active signals
- Quick notes and recent memory

## Tone Behaviors (Examples)
- Mentor: Measured pacing, guidance
- Strategist: Terse, directive
- Explorer: Questioning, rich suggestions
- Analyst: Facts first
- Guardian: Safety and clarity
