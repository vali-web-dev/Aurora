# Health Universe - Quick Reference

**Shortcuts:**
- `⌘⇧H` / `Ctrl+Shift+H` - Jump to Health
- `⌘M` - New mood entry
- `⌘E` - New exercise log
- `⌘S` - View sleep stats
- `⌘T` - View trends

**Quick Workflows:**

| Workflow | Steps |
| --- | --- |
| Log daily check-in | Dashboard → New Entry → Select type (mood/sleep/food/exercise) → Save |
| Track habit | Click New Habit → Set routine + frequency → Enable reminders → Watch streak |
| View health trends | Click Trends → Select time range → See patterns, correlations |
| Share with provider | Settings → Share with Provider → Generate link/QR → Provider accesses summary |
| Export report | Analytics → Select date range → Choose sections → Export PDF |

**Pro Tips:**
- **Correlation tracking**: Log multiple data types; AI surfaces patterns (mood + sleep + exercise)
- **Private by default**: Data local unless you explicitly export/share
- **Morning ritual**: Check-in first thing builds reflection habit
- **Crisis resources**: If crisis signal detected, resources surfaced immediately
- **Provider sharing**: Selective sharing (they see only what you authorize)
- **Wearable integration**: Sync with fitness trackers for continuous data

**Common Commands:**
```
Check-in types          → Mood, sleep, nutrition, exercise, symptoms, custom
Tracker creation        → Pick habit type, set frequency, enable alerts
Trends visualization    → Charts by day/week/month, correlations
Export formats          → PDF (shareable), CSV (data analysis), link (provider)
Privacy controls        → What's local, what's synced, what's shared
```
