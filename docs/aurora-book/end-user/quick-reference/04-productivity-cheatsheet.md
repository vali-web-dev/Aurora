# Productivity Universe - Quick Reference

**Shortcuts:**
- `⌘P` / `Ctrl+P` - Jump to Productivity
- `⌘T` - New task
- `⌘F` - Focus session (start timer)
- `⌘W` - Weekly review
- `⌘;` - Quick add from anywhere

**Quick Workflows:**

| Workflow | Steps |
| --- | --- |
| Capture task quickly | ⌘; → Type → Press Enter (added to today) |
| Time-block day | Calendar view → Drag time block → Link project/task → Done |
| Start focus session | Click Focus button → Timer starts (90 min default) → Notifications muted |
| Weekly review | Click Weekly Review → Scroll wins → Plan next week → Reschedule carry-overs |
| Archive project | Open project → Menu → Archive → Recoverable anytime |

**Pro Tips:**
- **Quick capture**: ⌘; works from any universe; captures to inbox
- **Focus signal**: Set in CP to minimize distractions (Entertainment/Social quiet)
- **Recurring tasks**: Create once, auto-generates each day/week
- **Time blocking**: Link physical time to goals; blocks sync to calendar
- **Batch review**: Weekly review takes 10 min but saves hours; don't skip
- **Habit tracking**: Streaks visible; breaks are OK, but consistency builds momentum

**Common Commands:**
```
Today view              → Tasks due today, prioritized
This week               → 7-day view with time blocks
Calendar                → Time-block view, drag to move
Recurring rules         → Daily/weekly/monthly/custom
Archive                 → Hidden but searchable; restore anytime
Stats                   → Completion rate, streak, trends
```
