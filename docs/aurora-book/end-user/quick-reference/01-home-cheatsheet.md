# Home Universe - Quick Reference

**Shortcuts:**
- `⌘H` / `Ctrl+H` - Jump to Home
- `⌘1` - Dashboard view
- `⌘2` - Quick settings
- `⌘3` - System status

**Quick Workflows:**

| Workflow | Steps |
| --- | --- |
| Review your day | Open Home → Scan summary cards → Check CP → Mark done |
| Jump to universe | Click universe card OR use global search (`⌘K`) → Select universe |
| Reset context | Open CP → Clear memory → Refresh page |
| Check status | Dashboard shows connected devices, notifications, health indicators (1 click) |

**Pro Tips:**
- **Customize layout**: Drag cards in edit mode to match your workflow
- **Quick access**: Pin most-used universes to top row
- **Multiple spaces**: Create different home layouts for different times of day
- **CP shortcuts**: Set CP to always-visible if you live in quick settings
- **Night mode**: Use dark theme or Illuminated mode for evening visits

**Common Commands:**
```
Summary (default view)          → Focus on key metrics
Quick Links (sidebar)           → Fast jump to universes
Notifications queue             → Clear or snooze together
System status                   → See all device health
Companion Panel (always)        → Persistent context
```
