# Brand Universe - Quick Reference

**Shortcuts:**
- `⌘B` / `Ctrl+Shift+B` - Jump to Brand
- `⌘O` - Brand overview
- `⌘A` - Asset library
- `⌘C` - Campaign timeline
- `⌘E` - Export brand kit

**Quick Workflows:**

| Workflow | Steps |
| --- | --- |
| Define brand | New Brand → Set mission/values/voice → Write tone guidelines → Share with team → Save |
| Upload assets | Asset Library → Create folder → Upload files → Add tags/usage rights → Organize |
| Review campaign | Campaign Timeline → Select draft → Check brand guidelines → Approve or request edits |
| Export kit | Menu → Export → Select format (PDF/Figma) + sections → Download package → Share with partners |
| Create template | Asset Library → New Template → Design using guidelines → Save as reusable → Team uses for consistency |

**Pro Tips:**
- **Living document**: Brand guidelines evolve; version history tracks changes over time
- **Team access**: Control who edits vs. who only views guidelines
- **Color standards**: Export as Pantone/Hex/RGB for print/web consistency
- **Typography lock**: Fix approved fonts to prevent casual substitutions
- **Campaign checklist**: Built-in brand alignment checklist before launch
- **Audit trail**: See who approved what and when in campaign history

**Common Commands:**
```
Brand hub               → Mission, values, tone, voice guidelines
Asset management        → Upload, tag, version control, usage rights
Color palette           → Hex/RGB/Pantone, export for design tools
Typography system       → Font families, sizes, weights, hierarchy
Campaign alignment      → Checklist, approvals, version tracking
Export options          → PDF (stakeholders), Figma (designers), raw files
```
