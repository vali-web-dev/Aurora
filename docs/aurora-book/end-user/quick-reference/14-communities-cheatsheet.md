# Communities Universe - Quick Reference

**Shortcuts:**
- `⌘K` / `Ctrl+Shift+K` - Jump to Communities
- `⌘D` - Directory search
- `⌘N` - New community
- `⌘E` - New event
- `⌘J` - Join community

**Quick Workflows:**

| Workflow | Steps |
| --- | --- |
| Find & join | Directory → Search topic → Preview community → Click Join → Introduce in intro thread |
| Start thread | Community home → New Post/Thread → Write topic → Add tags → Post → Await replies |
| Host event | Events tab → New Event → Set date/time/description → Invite members → Take RSVPs |
| Manage roles | Community Settings → Roles → Assign (member/moderator/admin) → Define permissions |
| Archive thread | Old thread → Menu → Archive → Hidden but searchable → Restore anytime |

**Pro Tips:**
- **Discovery**: Browse by interest; join communities aligned with your learning/hobbies
- **Moderation**: Mods keep community healthy; report rule violations
- **Threading**: Replies auto-thread; keeps conversations organized
- **Async-friendly**: No sync required; read and respond on your time
- **Searchable history**: Old threads findable; community knowledge preserved
- **Reputation**: Helpful members gain visibility; community self-polices quality

**Common Commands:**
```
Directory               → Search, filter by size/activity/topic
Community creation      → Public/private, rules, mod team
Thread/post creation    → Text, media, polls, links, code blocks
Event management        → Schedule, RSVP tracking, reminders
Moderation tools        → Mute, block, flag, roles, permissions
Export community        → Archive threads, download data
```
