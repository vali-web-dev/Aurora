# Travel Universe - Quick Reference

**Shortcuts:**
- `⌘T` / `Ctrl+T` - Jump to Travel
- `⌘⇧N` - New trip
- `⌘M` - Map view
- `⌘D` - Download maps (offline)
- `⌘J` - Trip journal

**Quick Workflows:**

| Workflow | Steps |
| --- | --- |
| Plan trip | New Trip → Set destination + dates → Add days → Link activities → Save |
| Book hotel | Search Hotels → Filter dates/price → View options/reviews → Click Book → Confirmation auto-tagged to trip |
| Track expenses | Add expense → Categorize as Travel → Tag with trip name → View total in summary |
| Download offline maps | Maps view → Select area → Click Download → Use without internet access |
| Export trip summary | Trip complete → Click Export → Choose format → Share or download |

**Pro Tips:**
- **Flexible itinerary**: Reorder days/activities anytime; trip adjusts automatically
- **Offline maps**: Download before leaving; navigate without data/WiFi
- **Multi-city**: Link multiple destinations; transitions auto-calculated
- **Travel insurance**: Available at booking time; protects trip investment
- **Shared trips**: Add collaborators; edit permissions control what they change
- **Journal entries**: Add notes and photos to trip; becomes travel memory

**Common Commands:**
```
Create itinerary        → Add days, reorder, nest activities
Link accommodations     → Hotel, Airbnb, camping (auto-price in budget)
Add activities          → Search or create custom
View map               → See locations, distances, travel times
Download offline       → Maps, bookings, documents all downloadable
Export trip            → PDF itinerary, cost summary, photos
```
