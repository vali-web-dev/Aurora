# Bonus Universes - Quick Reference

**Shortcuts:**
- `⌘?` / `Ctrl+?` - Help menu (access all docs)
- `⌘R` - Feedback/report issue
- `⌘⌛` - Roadmap
- `⌘🧪` - Enable beta features

**Quick Workflows:**

| Workflow | Steps |
| --- | --- |
| Check roadmap | Help menu → Roadmap → Filter by timeline (Now/Next/Later) → Vote on features → See status |
| Submit feedback | Help menu → Send Feedback → Rate experience → Add comments → Tell Aurora what to build |
| Access release notes | Home universe → Release Notes section → Read what's new → Follow links for details |
| Join announcements | Communities → Find Aurora official channel → Enable notifications → Get feature alerts |
| Enable beta testing | Settings → Labs or Experimental features → Toggle on → Try early features → Report bugs |

**Pro Tips:**
- **Vote on features**: Your votes drive roadmap priority; request features you want to see
- **Beta participation**: Try experimental features; your feedback shapes the product
- **Release notes**: Detailed changelogs by version; helps you understand what changed and why
- **Open roadmap**: Transparency about what's coming (Now/Next/Later); helps you plan
- **Community shaping**: Join feature discussions in Communities; voice matters in product direction
- **Early access**: Beta testers get features 4-6 weeks before public release

**Common Commands:**
```
Roadmap                 → View features by stage (Now/Next/Later/Research)
Feedback channels       → In-app form, email, GitHub issues, community threads
Release notes           → By version, with migration guides and FAQs
Beta features           → Labs section, experimental toggle, feedback loops
Community discussion    → Official Aurora channel, general feedback, feature requests
Change log              → Document history, archive old versions
```
