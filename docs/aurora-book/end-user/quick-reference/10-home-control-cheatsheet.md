# Home Control Universe - Quick Reference

**Shortcuts:**
- `⌘H` / `Ctrl+H` - Jump to Home Control
- `⌘A` - Add device
- `⌘R` - New routine/scene
- `⌘S` - View system status
- `⌘E` - Energy dashboard

**Quick Workflows:**

| Workflow | Steps |
| --- | --- |
| Add device | Add Device → Scan code or search → Confirm pairing → Name + assign room |
| Create routine | New Routine → Set trigger (time/location/voice) → Add actions → Test → Save |
| Toggle device | Dashboard → Find device/room → Click toggle → Confirm → Instant change |
| Set energy alert | Energy Dashboard → Click Set Alert → Choose device + threshold → Get notified |
| Manage security | Device Settings → Change password → Update firmware → Review access logs |

**Pro Tips:**
- **Scenes save time**: Create "Morning" scene to light up, heat up, and brew coffee in one tap
- **Automation**: Routines run without manual intervention (time-based, location-based, or voice-triggered)
- **Voice control**: Say "Alexa/Google, good night" to trigger full "Good Night" routine
- **Energy monitoring**: Track which devices use most power; reduce phantom loads
- **Security first**: Firmware auto-updates available; 2FA supported
- **Local network**: Data stays on your network unless you enable cloud sync

**Common Commands:**
```
Device management       → Add, rename, remove, update firmware
Routine/scene creation  → Trigger (time/location/voice), actions
Energy monitoring       → Real-time usage, historical trends, alerts
Security controls       → Passwords, 2FA, access logs, device pairing
Modes/automation        → Morning, evening, away, home, custom
Report generation       → Energy usage, automation runs, errors
```
