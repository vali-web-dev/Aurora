# Finance Universe - Quick Reference

**Shortcuts:**
- `⌘$` / `Ctrl+Shift+F` - Jump to Finance
- `⌘B` - View balance
- `⌘T` - New transaction
- `⌘G` - Budgets view
- `⌘A` - Account reconciliation

**Quick Workflows:**

| Workflow | Steps |
| --- | --- |
| Review budget monthly | Budgets → Click month → Scroll categories → Note overspend → Adjust limits |
| Track investment | New Investment → Enter ticker/shares/price → Set price alerts → Monitor performance |
| Reconcile account | Transactions → Compare to bank statement → Mark verified → Flag discrepancies |
| Set spending alert | Budget → Add alert threshold (e.g., $500 on dining) → Get notified when close |
| Create savings goal | New Goal → Name + target amount + timeline → Link account → Watch auto-suggestions |

**Pro Tips:**
- **Automated categorization**: Most transactions auto-categorize; edit manually if wrong
- **Linked transactions**: Link invoice to payment; creates audit trail
- **Price tracking**: Set alerts on investments; notified if targets reached
- **Spending correlation**: Link to Health/Productivity to see if spending correlates with mood/stress
- **Export for taxes**: Export transactions by category for year-end accounting
- **Snapshot reports**: Monthly, quarterly, annual snapshots for reflection

**Common Commands:**
```
Add account             → Bank, investment, credit card, manual
View transactions       → Filter by date, category, account
Create budget           → Set per-category limits
Set alerts              → Notify if spending approaches limit
Reconcile               → Mark transactions as verified
Export                  → PDF report, CSV for analysis
```
