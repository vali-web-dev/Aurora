# Learning Universe - Quick Reference

**Shortcuts:**
- `⌘L` / `Ctrl+L` - Jump to Learning
- `⌘E` - Enroll in course
- `⌘B` - Bookmark current lesson
- `⌘N` - New note (from any lesson)

**Quick Workflows:**

| Workflow | Steps |
| --- | --- |
| Start new course | Go to Dashboard → Browse or search → Enroll → Begin |
| Resume course | Dashboard → In Progress → Click → Continue |
| Save & review later | Bookmark lesson → Set reminder → Return when ready |
| Get help | Scroll to Q&A → Ask question → Community answers (or instructor) |

**Pro Tips:**
- **Spaced repetition**: Bookmark key concepts → Use weekly review to revisit
- **Mentor signal**: Set Learning signal in CP to get case studies and examples
- **Note taking**: Save directly to CP from lessons; they auto-organize by course
- **Export transcript**: After course completion, download with scores/skills
- **Cohort learning**: Join group courses to see peer progress and build accountability

**Common Commands:**
```
Browse courses          → Filtered by level, duration, skill
Apply for prerequisites → Required before course start
Join cohort (optional)  → Unlock peer discussions
Earn certificate        → Upon completion, shareable
Export progress         → View skills gained, scores
```
