# Social Universe - Quick Reference

**Shortcuts:**
- `⌘S` / `Ctrl+S` - Jump to Social
- `⌘N` - New post
- `⌘M` - Messages
- `⌘C` - Create group chat
- `⌘F` - Find friends/communities

**Quick Workflows:**

| Workflow | Steps |
| --- | --- |
| Share a moment | Click New Post → Choose visibility (private/friends/public) → Add text/media → Set tone (CP) → Post |
| React to friend | Scroll feed → Click post → React (emoji/thumbs) or Comment → Post reply |
| Create group chat | Click New Group Chat → Add friends → Name group → Start chatting |
| Manage followers | Profile → Followers tab → Review → Unfollow/block if needed |
| Archive post | Old post → Menu → Archive → Hides from public, recoverable |

**Pro Tips:**
- **Visibility by default**: Set default post visibility in Settings (private/friends/public)
- **Tone matters**: Set Companion Panel tone before posting; influences wording suggestions
- **Rich reactions**: React with emoji, GIF, or custom reaction
- **Threading**: Replies auto-thread; keeps conversations organized
- **Muting**: Mute friends' posts without unfollowing (still see close friends)
- **Smart notifications**: Only get alerts for close friends by default; customize per friend

**Common Commands:**
```
Compose post             → Text, image, video, link, poll
Set visibility           → Private (self only), Friends, Public
React options            → Emoji, thumbs, love, bookmark, reply
Thread replies           → Unlimited depth, quoted replies
Mute/Archive options     → Hide posts, mute notifications, archive
Export posts             → Personal archive, data portability
```
