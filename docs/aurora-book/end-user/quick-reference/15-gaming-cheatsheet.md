# Gaming Universe - Quick Reference

**Shortcuts:**
- `⌘G` / `Ctrl+Shift+G` - Jump to Gaming
- `⌘L` - Library/add game
- `⌘C` - Capture clip
- `⌘E` - Events/tournaments
- `⌘S` - Share highlight

**Quick Workflows:**

| Workflow | Steps |
| --- | --- |
| Add game | Library → Add Game → Search or manual entry → Link platform → Game appears with status |
| Capture highlight | During/after playing → Click Capture → Trim clip → Add title/tags → Save to archive |
| Share clip | Highlight → Click Share → Choose Social visibility → Generate link → Share with friends |
| Join tournament | Events view → Search tournament/game → Click Register → Join team if applicable → Track leaderboard |
| Track stats | Profile → View per-game stats (hours, rank, achievements) → Compare with friends → Unlock badges |

**Pro Tips:**
- **Multi-platform library**: Link Steam, PlayStation, Xbox, Nintendo, Epic accounts; library syncs
- **Clip auto-save**: Gaming universe auto-records last 30 sec; tap to preserve as highlight
- **Achievement tracking**: Badges unlock automatically; see progression toward 100%
- **Gaming groups**: Create private group to coordinate multiplayer sessions
- **Tournament finder**: Automated matching; beginner-friendly to competitive tiers
- **Streaming built-in**: Stream gameplay to friends (not public); chat as viewers watch

**Common Commands:**
```
Library management      → Add games, link platforms, track playtime
Highlight capture      → Auto-save, manual save, trim, label
Sharing options        → Private, friends-only, public with age gating
Tournament registration → Search, register, join team, track standing
Stats & achievements    → Per-game breakdown, badges, level progression
Social features         → Gaming groups, messaging, watch friends playing
```
