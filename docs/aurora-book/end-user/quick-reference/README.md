## How to Use These Cheatsheets

Each cheatsheet includes:

1. **Keyboard Shortcuts**: Quick keys for common actions
2. **Quick Workflows**: Table of 3-5 most common tasks with steps
3. **Pro Tips**: Advanced techniques and best practices
4. **Common Commands**: Menu items and UI options reference

**For printing**: Download PDF and print at 8.5" × 11" (US Letter) for desk reference.

**For keeping handy**: Pin, screenshot, or bookmark on your phone or tablet.

**For shared teams**: Print for each team member and hang by workspace.

## Master Shortcuts Quick Lookup

### Global Shortcuts (Work Everywhere)

| Shortcut | Action |
| --- | --- |
| `⌘K` / `Ctrl+K` | Global search (find anything) |
| `⌘,` (comma) | Settings |
| `⌘/` | Help menu |
| `⌘;` | Quick capture (add to task/note inbox) |
| `⌘?` | Documentation/help |
| `Esc` | Close panel or exit focus mode |

### Jump to Universe Shortcuts

| Shortcut | Universe |
| --- | --- |
| `⌘H` | Home |
| `⌘L` | Learning |
| `⌘C` | Create |
| `⌘P` | Productivity |
| `⌘⇧H` | Health |
| `⌘$` | Finance |
| `⌘S` | Social |
| `⌘E` | Entertainment |
| `⌘T` | Travel |
| `⌘⌘` | Home Control |
| `⌘A` | Automation |

### Companion Panel Shortcuts

| Shortcut | Action |
| --- | --- |
| `⌘CP` | Toggle Companion Panel |
| `⌘↑` | Expand CP |
| `⌘↓` | Collapse CP |
| `⌘0` | Pin/unpin CP |

## Printing Tips

1. **Color**: Print in color for visual clarity; black & white also works
2. **Layout**: Use landscape orientation for tables and compact layout
3. **Binding**: Hole-punch and bind at edge for desk reference
4. **Laminating**: Optional; protects from coffee spills and wear
5. **Updates**: As Aurora evolves, cheatsheets auto-update; reprint quarterly
