# Commerce Universe - Quick Reference

**Shortcuts:**
- `⌘Shop` / `Ctrl+Shift+C` - Jump to Commerce
- `⌘F` - Search products
- `⌘+` - Add to cart
- `⌘♥` - Add to wishlist
- `⌘H` - View order history

**Quick Workflows:**

| Workflow | Steps |
| --- | --- |
| Find & compare | Search/browse → Add to comparison list → View side-by-side → Pick winner → Add to cart |
| Checkout | Review cart items → Check pricing/shipping → Proceed → Confirm order → Auto-tagged to Finance |
| Return item | Order History → Find item → Click Return → Select reason → Print label or arrange pickup |
| Create wishlist | Browse → Click heart/menu → Add to Wishlist → Create collection → Share with friends |
| Track price | Find product → Set Price Alert → Get notified when drops → Quick checkout link provided |

**Pro Tips:**
- **Smart filters**: Use ethical filters (fair trade, sustainable, local) to filter results
- **Price history**: View how price changed over time; identifies good deal moment
- **Wishlist sharing**: Share collections with friends; they can gift directly
- **Auto-categorization**: Purchases auto-link to Finance; see spending patterns
- **Return window**: Clear return window shown at purchase; no surprise deadlines
- **Rating system**: Leave reviews after purchase; helps community and future shoppers

**Common Commands:**
```
Search & filter         → Category, price range, ratings, ethical criteria
Product comparison      → Feature matrix, price, shipping, reviews
Add to cart            → Quantity, size, options adjusted before checkout
Checkout flow          → Shipping address, payment, confirmation
Order tracking         → Real-time updates, carrier tracking
Wishlist management    → Create, edit, share, track price drops
```
