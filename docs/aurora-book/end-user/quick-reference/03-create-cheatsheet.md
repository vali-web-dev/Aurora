# Create Universe - Quick Reference

**Shortcuts:**
- `⌘C` / `Ctrl+C` - Jump to Create
- `⌘N` - New project
- `⌘S` - Save/checkpoint
- `⌘V` - View version history
- `⌘Shift+S` - Share project

**Quick Workflows:**

| Workflow | Steps |
| --- | --- |
| Start new project | New → Pick template or blank → Name → Begin editing |
| Save checkpoint | Ctrl+S → Auto-saves, checkpoint created in version history |
| Collaborate real-time | Share → Add team → Start editing together → Changes sync |
| Export work | Menu → Export → Choose format (PNG/PDF/HTML) → Download |
| Iterate with feedback | Share draft → Get comments → Incorporate → Version tracked |

**Pro Tips:**
- **Templates save time**: Start from template for consistency
- **Version history**: Never lose work; browse and restore old versions anytime
- **Real-time collaboration**: Cursor positions show team's work location
- **Comment threads**: Leave inline feedback without derailing work
- **Auto-save**: Every edit auto-saves; no manual save needed

**Common Commands:**
```
Edit modes               → Full editor, fullscreen, comment-only, view-only
Version control         → Create, restore, compare versions side-by-side
Share settings          → Public link, email invite, role-based access
Export formats          → PNG (raster), PDF (print), HTML (web), SVG (vector)
Undo/Redo               → Full history, jump to any point
```
