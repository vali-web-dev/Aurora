# Entertainment Universe - Quick Reference

**Shortcuts:**
- `⌘E` / `Ctrl+E` - Jump to Entertainment
- `⌘P` - Play (resume watching/reading)
- `⌘L` - Add to Watchlist
- `⌘R` - Rate content
- `⌘D` - Download for offline

**Quick Workflows:**

| Workflow | Steps |
| --- | --- |
| Start watching | Search or browse → Click title → View details → Click Watch → Play from bookmark |
| Build watchlist | Browse content → Heart icon or menu → Add to Watchlist → Organize in collections |
| Rate & review | After watching/reading → Click Rate → Select rating → Optional: Write review → Share |
| Host watch party | Find title → Click Watch Party → Invite friends → Sync group viewing + chat |
| Download offline | Browse title → Click Download → Reduces quality for smaller size → Watch anywhere |

**Pro Tips:**
- **Resume watching**: Automatically bookmarks where you left off; pick up exactly there
- **Smart recommendations**: Rate content you watch; AI improves suggestions over time
- **Private history**: History local by default; watchlist is private unless shared
- **Collection organization**: Create collections like "Must Watch", "Rainy Days", "With Friends"
- **Offline sync**: Download titles to watch on plane/train without internet
- **Sharing clips**: Some platforms allow short clip shareable links for Social integration

**Common Commands:**
```
Discovery modes         → Trending, recommended, by genre, by time (short/long)
Watchlist organization  → Create collections, reorder, share
Continue watching       → Resume at exact timestamp
Rate + review           → Stars, thumbs, written review
Watch party             → Real-time sync, multi-user (2-8 friends typical)
Download options        → Quality levels (affects file size, streaming smoothness)
```
