# Keyboard Shortcuts

These shortcuts help you move quickly across Aurora.

## Navigation
- Tab: Move between elements
- Enter: Activate
- Esc: Close dialogs and exit
- Up/Down: Navigate lists


## Global
- Ctrl+K or S: Global search (mobile)
- Ctrl+/: Open documentation portal
- Ctrl+B: Toggle Companion Panel
- Ctrl+H: Go to Home
- Ctrl+Shift+L: Go to Learning
- Ctrl+Shift+F: Go to Create
- Ctrl+Shift+P: Go to Productivity
- ?: Open keyboard shortcuts help


## Top Navigation
- Theme selector button: Theme and mode
- CP: Companion Panel
- Bell icon: Notifications

## Notes
- Standard OS editing shortcuts apply within text fields.
- You can view the full list in the Keyboard Shortcuts help modal.
