# Accessibility and Inclusivity

Aurora is built for everyone and targets high accessibility standards.

## Core Accessibility Features
- WCAG AAA intent (contrast, structure, semantics)
- Full keyboard navigation
- Visible focus indicators
- Screen reader optimization with semantic HTML and ARIA
- Reduced motion support
- High contrast mode
- Large text option
- Dyslexic-friendly font option

## Accessibility in Universes
- Learning: Transcripts for videos and downloadable materials
- Create: Alt text requirements and contrast checks
- Productivity: Exportable data
- Health: Clear language and transparency
- Finance: Accessible charts and CSV export

## Accessibility Checklist (Before Shipping)
- Keyboard navigable
- Screen reader tested
- Contrast verified
- Motion reducible
- Clear labels and error messages

## Personal Accessibility Settings
- Reduce motion (respects system preference)
- High contrast mode
- Large text option
- Dyslexic-friendly font option

## Screen Reader Guidance
- Headings are hierarchical for easy navigation
- Dialogs announce themselves when opened
- Live updates announce status changes

## Keyboard Navigation Tips
- Use Tab to move between elements
- Use Esc to close modals
- Focus indicators are visible on interactive elements
