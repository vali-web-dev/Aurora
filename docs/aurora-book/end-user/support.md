# Support and Community

## Help Channels
- In-app help: Use the help button
- Docs portal: Central documentation
- Community forums
- Support email

## Response Expectations
- Accessibility issues: priority handling
- Privacy concerns: confidential response
- Security reports: acknowledged quickly

## Reporting Issues
- Bug reports: Include steps and screenshots
- Accessibility: Priority support
- Privacy: Confidential handling
- Security: Responsible disclosure

## What To Include in a Bug Report
- What you expected to happen
- What actually happened
- Steps to reproduce
- Browser and device details

## Community
- Forums for questions and ideas
- Live sessions and updates
- Roadmap voting
