## Step-by-step Guides

### Add a Smart Device
1. Open Home Control and go to Add Device.
2. Scan the device code or search by name.
3. Confirm pairing in device app.
4. Name and assign to room.

### Create a Routine
1. Click New Routine.
2. Set trigger (time, location, voice command).
3. Add actions (light on, doors locked, etc.).
4. Test and activate.

### Control Devices Manually
1. Open Home Control dashboard.
2. Find device or room.
3. Click to toggle or adjust.
4. Confirm change.

### Set Energy Monitoring Alerts
1. Open Energy Dashboard.
2. Click Set Alert.
3. Choose device or room.
4. Set threshold (e.g., over 500W).
5. Receive alert if exceeded.

### Manage Device Security Settings
1. Click Device Settings.
2. View access logs.
3. Change password or update firmware.
4. Manage which users can control device.
5. Enable 2FA if available.

### View Automation History
1. Open Automation or Routines.
2. Click History.
3. See all recently executed routines.
4. View timestamp and result.
5. Debug if routine didn't run as expected.

## Visual Guide

**Home Control Dashboard**
> Overview of all connected smart home devices grouped by room or device type. Shows device status (On/Off, brightness, temperature). Key elements: Device cards showing current state, toggle switches for on/off, quick adjustment sliders for dimming/temperature, device icons, room grouping headers.

**Add Device Pairing**
> Interface to discover and pair new smart devices. Shows available devices ready to pair, step-by-step pairing instructions, and device naming. Key elements: Device list with pairing status indicators, pairing code entry if needed, device naming field, room assignment selector, confirmation button.

**Routine Creation & Automation**
> Setup interface for automations (e.g., Morning Routine, Movie Mode). Shows trigger conditions, actions to perform, and scheduling options. Key elements: Routine name field, trigger selector (time/location/manual/voice), action list (lights on/off, A/C settings), save button, times of day quick presets.
