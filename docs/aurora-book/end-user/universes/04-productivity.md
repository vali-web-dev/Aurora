## Step-by-step Guides

### Create a Task and Add to Today
1. Open Productivity and click New Task.
2. Enter task name and set due date.
3. Click Add to Today (or later date).
4. Task appears in your daily list.

### Break a Project into Milestones
1. Create a new Project.
2. Outline major milestones.
3. Add tasks to each milestone.
4. Track progress toward completion.

### Review Your Week
1. Click Weekly Review.
2. Check completed tasks and wins.
3. Plan next week's priorities.
4. Archive or reschedule tasks.

### Set Up Recurring Tasks
1. Click New Task.
2. Add task name and due date.
3. Click Recurring.
4. Set frequency (daily, weekly, monthly).
5. Task auto-creates on schedule.

### Use Time Blocking
1. Open Calendar view.
2. Block time for focus (e.g., 9-11am for deep work).
3. Link a project to the time block.
4. Add task to fill the block.
5. During block, focus mode can activate.

### Archive Completed Projects
1. Open a finished project.
2. Click Archive.
3. Project moves out of active view.
4. Search archives anytime to recover.

## Visual Guide

**Today's View**
> Shows tasks due today, organized by project or priority. Each task displays title, estimated effort/time, assigned person (if team), and priority level. Key elements: Task list with checkboxes, drag-to-reorder, priority indicators (color-coded), time estimate badges.

**Project with Milestones**
> Displays project overview with milestone timeline or roadmap. Shows milestone cards with completion percentage, tasks within milestone, and deadline status. Key elements: Milestone cards or timeline, task count per milestone, completion percentage, due date indicators.

**Weekly Review Summary**
> End-of-week review showing completed tasks, metrics, and predictions for next week. Displays tasks completed, time logged, and recommended focus areas. Key elements: Completion count, time spent chart, top contributors (if team), recommended tasks for next week.
