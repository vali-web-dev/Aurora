# Learning Universe

## Purpose
Grow skills with structured paths, progress tracking, and mentorship.

## What It Is
- Curated learning paths and courses
- Progress tracking and achievements
- Community discussions and Q and A
- Goal scaffolding and milestones

## Who Uses It
- Students, career-switchers, lifelong learners
- Anyone building new skills

## Companion Tone
Mentor (encouraging, progressive, example-rich)

## Key Features
- Personalized learning paths
- Spaced repetition and review reminders
- Peer discussions and mentor matching
- Milestone celebrations
- Transcript and credential export

## Core Surfaces
- Learning dashboard (current paths and progress)
- Course detail pages (lessons, exercises, resources)
- Progress tracker and achievements
- Discussion and Q and A threads

## Key Actions
- Enroll in a course and start a lesson
- Track progress and resume where you left off
- Save notes to Companion Panel
- Export transcripts and credentials

## Signals and Personalization
- Learning signal boosts scaffolding and examples
- Focus signal narrows to current lesson only
- Reflection signal surfaces insights and review prompts

## Notifications
- Optional reminders for review and milestones
- No notifications without explicit opt-in

## How To
- Start a course: open Learning and pick a path.
- Resume progress: return to the dashboard and continue.
- Review later: save notes in CP and set a reminder.

## Common Workflows
- Learning session with notes in Companion Panel
- Apply a lesson in Create, then return for review

## Step-by-step Guides

### Enroll in a Course
1. Open Learning dashboard.
2. Browse or search for a course.
3. Click Enroll.
4. Confirm and start first lesson.

### Save a Note and Review Later
1. While in a lesson, save a note in CP.
2. Set a reminder if desired.
3. Return to the course to continue.

### Ask a Question in Q and A
1. Scroll to the Q and A section.
2. Click Ask a question.
3. Write your question and submit.

### Export a Certificate
1. Open a completed course.
2. Click View Certificate.
3. Download or share via link.
4. Certificate includes course name, completion date, and skills gained.

### Track Group Learning Progress
1. Open a group study or cohort course.
2. View peer progress on leaderboard.
3. See discussion contributions.
4. Compare milestones reached.

### Create Study Notes and Flashcards
1. Open a lesson.
2. Click Create Flashcard.
3. Add question and answer.
4. Organize by topic.
5. Review with spaced repetition.

## Visual Guide

**Learning Dashboard**
> Shows active courses and progress overview. Displays course cards with thumbnail images, progress bars, enrollment date, and next due date. Key elements: Course grid, progress indicators, Resume or Start button on each card, filter options (Active/Completed/Archived).

**Course Lesson View**
> Inside a course, shows lesson list with expandable sections and lesson metadata. Displays video duration, estimated completion time, and completion checkmarks. Key elements: Lesson hierarchy (Module > Lesson > Content), progress tracking, estimated time badges.

**Q&A Discussion Thread**
> Community question-answer thread within or beside the course. Shows question, multiple answers with upvotes, instructor-marked correct answers. Key elements: Question title, answer cards with vote counts, instructor badge, helpful/not helpful buttons.
