## Step-by-step Guides

### Create Your Brand Overview
1. Open Brand and click New Brand.
2. Define your mission, values, and voice.
3. Write tone guidelines (formal, casual, etc.).
4. Save and share with team.

### Upload and Organize Assets
1. Click Asset Library.
2. Create folders by type (logos, colors, fonts).
3. Upload files and add tags.
4. Set usage rights if team access needed.

### Review a Campaign for Alignment
1. Open Campaign Timeline.
2. Select a campaign draft or brief.
3. Check against brand guidelines.
4. Approve or request edits.

### Share Brand Guidelines with Team
1. Open Brand Overview.
2. Click Share or Invite.
3. Add team members.
4. Set permissions (view, edit, approve).
5. Team members access brand hub.

### Export Brand Kit
1. Click Export or Download.
2. Choose format (PDF, Figma file, etc.).
3. Select sections (colors, fonts, logos, tone).
4. Download package.
5. Share with external partners.

### Create Brand Templates
1. Open Asset Library.
2. Click Create Template.
3. Design with brand guidelines.
4. Save as reusable template.
5. Team uses for consistent outputs.

## Visual Guide

**Brand Overview**
> High-level brand summary showing mission statement, brand voice description, core values, and visual identity preview. Key elements: Mission statement displayed prominently, brand voice attributes (e.g., Friendly, Professional), core values listed, color palette swatches, logo area.

**Asset Library**
> Organized repository of brand assets (logos, icons, fonts, photos) searchable and filterable. Shows assets grouped by type with preview thumbnails. Key elements: Asset categories (Logos/Icons/Fonts/Photos), search bar, view/download buttons, version indicator, usage guidelines link per asset.

**Campaign Alignment Review**
> Review tool showing proposed campaign against brand guidelines. Highlights alignment scores and suggests improvements. Key elements: Campaign name, alignment checklist (Voice, Visuals, Values), green/yellow/red indicators, suggestions panel, approve/request changes buttons.
