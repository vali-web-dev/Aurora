## Step-by-step Guides

### Start a New Project
1. Open Create and click New Project.
2. Choose a template or start blank.
3. Name your project.
4. Begin editing.

### Share Your Work for Feedback
1. Click Share on your project.
2. Copy the link or invite collaborators.
3. Set permissions (view, comment, edit).
4. Collaborators can view and comment.

### Export Your Creation
1. Click the menu on your project.
2. Select Export.
3. Choose format (PNG, PDF, HTML).
4. Download.

### Use Version History
1. Open a project.
2. Click Version History (in menu).
3. Browse past versions by date.
4. Click a version to preview.
5. Click Restore to revert if needed.

### Collaborate in Real-time
1. Click Share on your project.
2. Invite collaborators (view, edit, or manage roles).
3. Multiple editors see live cursor positions.
4. Changes sync instantly.
5. Review edit history.

### Create from Template
1. Open Create and click New Project.
2. Select Browse Templates.
3. Preview template categories.
4. Click Use This Template.
5. Customize and rename.

## Visual Guide

**Project Dashboard**
> Lists all projects with project cards showing title, cover image/thumbnail, last modified date, collaborators, and project status. Key elements: Project tiles sorted by recency or custom order, New Project button, search/filter options, star/favorite toggle per project.

**Project Editor Interface**
> Main editing canvas/interface for content. Shows rich editor with toolbar (formatting, insert media, etc.), main content area, and sidebar with properties/layers. Key elements: Formatting toolbar, content area, version history toggle, real-time collaborator cursors.

**Share & Permissions Panel**
> Modal or sidebar showing sharing options. Displays individual user access controls (Viewer/Editor/Owner), public link option with copy button, and expiration date settings. Key elements: Permission dropdown per person, add collaborator field, public link toggle with access level indicator.
