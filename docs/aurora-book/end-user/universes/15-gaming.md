## Step-by-step Guides

### Add a Game to Your Library
1. Open Gaming and click Add Game.
2. Search for the game or add manually.
3. Link platform account if available.
4. Game appears in library with status.

### Save and Share a Highlight
1. During or after playing, click Capture.
2. Trim the clip if needed.
3. Add a title and tags.
4. Share to Social or keep private.

### Join a Tournament
1. Open Events view.
2. Search for tournament or by game.
3. Click Register.
4. Join team if applicable.
5. Check leaderboard during event.

### Track Game Stats and Achievements
1. Open Gaming profile.
2. View stats for each game (hours, rank, etc.).
3. Browse Achievements.
4. Unlock badges for milestones.
5. Compare with friends.

### Create Gaming Group
1. Click Communities or Friends.
2. Click Create Group.
3. Name group and invite friends.
4. Share gaming schedule.
5. Coordinate multiplayer sessions.

### Stream Gameplay
1. Open a game.
2. Click Stream or Go Live.
3. Choose quality and title.
4. Invite friends to watch.
5. Chat with viewers in real-time.

## Visual Guide

**Gaming Library**
> Personal game library showing owned games with status (installed, not installed, update available). Shows game cover art, title, play time logged, and last played date. Key elements: Game tiles with cover images, favorite heart icon, status badges (New/Update Available), play time logged, last played indicator, install/play button.

**Clip Capture & Editing**
> Interface to record, review, and edit gameplay clips. Shows clip timeline, trimming tools, and sharing options. Key elements: Clip preview/thumbnail, timeline scrubber for trimming, length indicator, annotation tools (text, shapes, highlights), share buttons, save/export options.

**Tournament Registration & Leaderboard**
> Tournament listings with registration and live leaderboard. Shows standings, rankings, and player stats. Key elements: Tournament banner with title/dates/prize pool, Register button, leaderboard table (rank, player name, score, wins), filter by game type, update frequency indicator (Real-time).
