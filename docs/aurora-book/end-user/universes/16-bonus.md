## Step-by-step Guides

### Using the Roadmap
1. Open docs portal and navigate to Roadmap.
2. Filter by timeline (Now, Next, Later).
3. View details for each planned feature.
4. Vote or comment to show interest.

### Staying Updated on Release Notes
1. Open Home universe.
2. Check Release Notes section.
3. Read what's new and changed.
4. Follow links for deeper information.

### Joining Community Announcements
1. Open Communities.
2. Find official Aurora channel.
3. Enable notifications for this community.
4. Receive alerts on new features.

### Submit Feature Requests
1. Open Roadmap or feedback portal.
2. Click Suggest Feature.
3. Describe your idea and use case.
4. Vote on existing requests.
5. See status of your suggestions.

### Provide Feedback on New Features
1. After trying a new feature, click Send Feedback.
2. Rate your experience.
3. Add detailed comments.
4. Report bugs if found.
5. Feedback helps shape Aurora.

### Beta Test Upcoming Features
1. Go to Settings or Labs section.
2. Enable Beta or Experimental features.
3. Try early versions of new features.
4. Report issues or suggestions.
5. Early testers shape product direction.

## Visual Guide

**Roadmap with Timeline Filters**
> Visual representation of Aurora's development roadmap organized by timeline or version. Shows planned features with status (Planned/In Progress/Shipped) and estimated ship date. Key elements: Timeline header with version numbers, feature cards showing status badge, estimated ship date, and related universes, filter by status/universe dropdown.

**Release Notes in Home**
> Displayed in Home universe when new version releases. Shows new features, improvements, and known issues. Key elements: Release date, version number, grouped sections (New Features, Improvements, Bug Fixes, Known Issues), feature icon and description, try-it buttons for new features.

**Aurora Official Community Channel**
> Dedicated community space for Aurora announcements, feature discussions, and user feedback. Shows pinned announcements, discussion threads, guidelines. Key elements: Community header, pinned announcements section, discussion threads sorted by activity, official Aurora badge on announcements, participation stats.
