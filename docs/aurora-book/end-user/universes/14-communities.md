## Step-by-step Guides

### Find and Join a Community
1. Open Communities and click Directory.
2. Search by topic or browse categories.
3. Click on community name to preview.
4. Click Request Access or Join Now.

### Start a Discussion Thread
1. Open Community home.
2. Click New Post or New Thread.
3. Write your topic or question.
4. Tag relevant topics if available.
5. Post.

### Host a Community Event
1. Click Events tab in your community.
2. Click New Event.
3. Set date, time, and description.
4. Invite members.
5. Post event and take RSVPs.

### Manage Community Roles
1. Open Community Settings.
2. Click Roles or Members.
3. Assign roles (moderator, member, admin).
4. Define what each role can do.
5. Members see their roles.

### Archive a Discussion
1. Open a discussion thread.
2. Click menu (three dots).
3. Select Archive.
4. Thread hidden but searchable.
5. Can be restored if needed.

### Create Featured Announcements
1. Create a post or thread.
2. Click Pin or Feature.
3. Select placement (top of feed, sidebar).
4. Set duration if temporary.
5. All members see immediately.

## Visual Guide

**Community Directory**
> Browsable or searchable list of communities. Shows community cards with name, description, member count, and join button. Key elements: Community cards with icon/cover image, description preview, member count badge, category tags, join button, favorite toggle.

**Community Home with Threads**
> Community's main page showing description, member list preview, and recent discussion threads. Threads show author, title, reply count, most recent activity time. Key elements: Community header with name/description, member list (avatars), thread list showing recent activity, post new thread button, sticky important thread area.

**Event Creation & RSVP**
> Interface to create events or RSVP to existing community events. Shows event details, attendee list, and RSVP options. Key elements: Event date/time display, location address, event description, RSVP button (Going/Interested/Not Going), attendee avatars, share event button.
