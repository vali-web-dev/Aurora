## Step-by-step Guides

### Log a Wellness Entry
1. Open Health and click New Entry.
2. Select entry type (mood, sleep, exercise, nutrition).
3. Fill in details and observations.
4. Save.

### Review Health Trends
1. Open Trends or Analytics.
2. Select a time period (week, month).
3. View charts and patterns.
4. Get personalized insights.

### Set a Health Goal
1. Click New Goal.
2. Choose goal type or create custom.
3. Set target and timeline.
4. Activate to start tracking.

### Share with Healthcare Provider
1. Open Health and go to Settings.
2. Click Share with Provider.
3. Generate a secure link or QR code.
4. Provider can access your summary.
5. Control what data is visible.

### Track Symptoms Over Time
1. Create a symptom tracker.
2. Log daily or weekly.
3. Correlate with other data (mood, activity).
4. View patterns over months.
5. Export summary for clinician.

### Export Monthly Health Report
1. Click Reports or Analytics.
2. Select date range.
3. Choose sections to include.
4. Export as PDF or CSV.
5. Share with team or provider.

## Visual Guide

**Health Dashboard**
> Shows today's logged health data and metrics at a glance. Displays cards for each metric (steps, sleep, mood, water, exercise) with today's value and daily goal progress bar. Key elements: Metric cards with progress bars, quick log buttons, trending indicator (up/down/stable arrow), color coding by status (on-track/behind).

**Trends & Analytics View**
> Historical view of metrics over selected time period (week/month/year). Displays line or bar charts showing trends, min/max/average values, and comparison to previous period. Key elements: Time period selector, chart with trend visualization, statistics summary (average, best day, consistency score).

**Goal Creation & Tracking**
> Interface to create new goals and track progress. Shows goal details, target value, deadline, and visual progress indicator. Key elements: Goal creation form, progress toward target, milestone markers, success notification when goal reached.
