## Step-by-step Guides

### Plan a Trip Itinerary
1. Open Travel and click New Trip.
2. Set destination and dates.
3. Add days and activities.
4. Pin places on the map.

### Book Accommodation
1. Click Search Hotels.
2. Filter by date range and price.
3. View options and reviews.
4. Click Book and confirm.

### Track Trip Expenses
1. Add a transaction manually or link a card.
2. Categorize as Travel.
3. Tag with trip name.
4. View total trip cost in summary.

### Download Offline Maps
1. Open Maps in Travel.
2. Click Download or Offline.
3. Select destination area.
4. Download for offline use.
5. Navigate without internet access.

### Get Travel Insurance
1. Open a booking or trip.
2. Click Add Insurance.
3. Compare insurance options.
4. Select coverage level.
5. Purchase bundled with trip.

### Connect Airport Transportation
1. Add your airport to itinerary.
2. Click Transportation.
3. Search rides (taxi, rental, rideshare).
4. Check prices and availability.
5. Book directly from app.

## Visual Guide

**Trip Planning with Map**
> Interactive map showing destination, trip route, and planned stops. Shows destination city highlighted, flight route if applicable, and pin markers for activities. Key elements: Zoomable/draggable map, destination marker, itinerary pins with dates, hotels/restaurants marked on map, trip duration badge.

**Itinerary Day-by-Day**
> Detailed day breakdown showing activities, locations, times, and logistics. Each day shows morning/afternoon/evening activities with addresses and travel time between. Key elements: Day headers, time slots with activities, location address with map link, duration/travel time, notes field per activity.

**Hotel Search & Booking**
> Search results for accommodations with filtering and comparison. Shows hotel cards with image, name, price, rating, and key amenities. Key elements: Hotel photo, price per night, guest rating (stars), key amenities icons, booking button, view details/policies link.
