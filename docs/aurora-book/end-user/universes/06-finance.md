## Step-by-step Guides

### Review Your Monthly Budget
1. Open Finance and go to Budget.
2. Check spending by category.
3. Note any overspend areas.
4. Adjust limits for next month if needed.

### Track an Investment
1. Click New Investment.
2. Enter details (ticker, shares, purchase price).
3. Set alerts for price targets.
4. View performance over time.

### Reconcile an Account
1. Open Transactions.
2. Compare against bank statement.
3. Mark verified transactions.
4. Flag any discrepancies.

### Set Spending Alerts
1. Open Budget or Insights.
2. Click Add Alert.
3. Set category and threshold (e.g., over $500 in dining).
4. Choose notification method.
5. Receive alert when limit approaches.

### Create a Savings Goal
1. Click New Goal.
2. Enter goal name and target amount.
3. Set timeline (3 months, 1 year, etc.).
4. Link to account.
5. View progress and auto-save suggestions.

### View Investment Performance
1. Open Portfolio or Investments.
2. See gain/loss overview.
3. View individual holdings.
4. Check performance vs. benchmarks.
5. Export performance report.

## Visual Guide

**Finance Dashboard**
> Overview of financial accounts, balances, and quick stats. Displays total net worth or checking balance prominently, recent transactions, and budget progress. Key elements: Account cards showing balance and institution name, recent transaction list (date, description, amount), quick action buttons (Transfer, Deposit).

**Budget Breakdown by Category**
> Pie chart or bar chart showing spending by category (Food, Transport, Entertainment, etc.). Each category shows total spent and remaining budget with color coding. Key elements: Category breakdown with percentage, spent vs budget comparison, drill-down to see category transactions, month/period selector.

**Investment Portfolio View**
> Shows investment accounts with holdings, current values, and performance. Displays each investment with shares/units, cost basis, current value, and gain/loss. Key elements: Investment list or chart view, performance indicators (green for gains, red for losses), view options (list/grid), asset allocation pie chart.
