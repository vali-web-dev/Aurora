## Step-by-step Guides

### Share a Moment
1. Open Social and click Create post.
2. Choose visibility (private, friends, public).
3. Add text or media.
4. Set tone in CP if desired.
5. Share.

### Respond to a Friend
1. Open their post or message.
2. Click Reply or React.
3. Write your response.
4. Send.

### Join a Community
1. Browse or search for community.
2. Click Join or Request Access.
3. Introduce yourself in intro thread.
4. Start participating.

### Create a Group Chat
1. Open Messages or Social.
2. Click New Group Chat.
3. Add friends or contacts.
4. Name the group.
5. Start chatting.

### Manage Followers and Following
1. Open your Profile.
2. Click Followers or Following tab.
3. View connections.
4. Unfollow or block if needed.
5. Manage who can see your posts.

### Archive Old Posts
1. Open your profile.
2. Find a post to archive.
3. Click menu (three dots).
4. Select Archive.
5. Post hidden from public view but recoverable.

## Visual Guide

**Social Feed View**
> Chronological or algorithmic feed of posts from followed people/communities. Shows post author, content/caption, media (images/video), engagement metrics (likes, comments, shares). Key elements: Post cards with author avatar, reaction buttons, comment icon, share button, timestamp.

**Post Creation Dialog**
> Interface to write and publish a new post. Shows text input area, media upload buttons, emoji picker, and optional settings (audience level, schedule time). Key elements: Text input field, media/attachment buttons, optional privacy selector (Public/Friends/Private), post button.

**Community Discussion View**
> Thread-based conversation showing original post and reply chain. Shows messages with author, timestamp, and nested replies. Key elements: Original post at top, reply messages chronologically ordered, indentation for nested replies, add reply input at bottom.
