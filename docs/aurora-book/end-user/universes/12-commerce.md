## Step-by-step Guides

### Find and Compare Products
1. Open Commerce and search or browse categories.
2. Add items to a comparison list.
3. View side-by-side to evaluate.
4. Click on winner to add to cart.

### Complete a Purchase
1. Review items in cart.
2. Review pricing and shipping.
3. Proceed to checkout.
4. Confirm and place order.

### Return an Item
1. Open Orders.
2. Find the item and click Return.
3. Select reason.
4. Print label or arrange pickup.

### Manage Wishlists and Collections
1. Open Wishlist or Collections.
2. Create custom collections (e.g., "Summer Items").
3. Add items from product pages.
4. Share collections with friends.
5. Get alerts when items go on sale.

### Track Price History
1. Open a product page.
2. Click Price History or Graph.
3. View price trend over time.
4. See historical lows.
5. Decide best time to buy.

### Set Up Price Alerts
1. Find a product you want.
2. Click Set Alert or Watch Price.
3. Enter target price.
4. Receive notification when price drops.
5. Quick checkout link provided.

## Visual Guide

**Commerce Homepage**
> Browse for products organized by category. Shows featured products, sales, and personalized recommendations. Key elements: Category navigation menu (top or sidebar), product grid with image/name/price, filter options (price, rating, brand), search bar, shopping cart button with count.

**Product Comparison Grid**
> Side-by-side comparison of multiple products showing specs, price, rating, and features. User can select 2-5 products to compare. Key elements: Product images at top, feature rows showing values for each product, price comparison highlight, add to cart buttons, specs table showing all details.

**Checkout Review Screen**
> Final review before purchase showing items, quantities, prices, shipping address, and payment method. Shows subtotal, tax, shipping, and total. Key elements: Order summary list, address shown prominently, shipping estimate, payment method badge, coupon entry field, Place Order button.
