# Multi-Universe Workflows

Real life doesn't happen in silos. This guide shows how Aurora's 15 universes work together seamlessly for common scenarios.

## Scenario 1: Plan and Execute a Weekend Getaway

A complete trip from inspiration to memories.

### The Journey

**Start**: Sunday afternoon, you want to escape next weekend  
**End**: Return home with photos, memories, expenses tracked, friends connected  
**Universes involved**: Travel → Finance → Commerce → Social → Entertainment → Home Control

### Step-by-Step Workflow

#### Phase 1: Plan the Trip (Travel)
1. Open **Travel** and click New Trip
2. Set destination (e.g., "Mountain Cabin Weekend")
3. Set dates (Friday evening - Sunday afternoon, 2 nights)
4. Add rough activities: hiking, campfire, board games
5. Save the trip (Companion Panel shows "Travel" scope)

#### Phase 2: Budget and Book (Finance + Commerce)
1. Open **Finance** and create a Budget for this trip
2. Estimate costs: accommodation ($150), food ($100), activities ($50), gas ($80)
3. **Total: $380** – check if this fits your monthly budget
4. Switch to **Commerce** and book accommodation
   - Search hotel with Travel destination linked
   - Pay via integrated payment
   - Confirmation automatically tagged to trip in Finance
5. Back in **Finance**, transaction is already categorized and trip-linked

#### Phase 3: Invite Friends (Social)
1. Open **Social** and create a Post:
   - "Mountain trip next weekend! Who's in?"
   - Share specific dates and location
   - Add mood/tone via Companion Panel (e.g., "Relaxed, social, exploratory")
2. Friends reply with interest
3. Friends who want to join: add them in **Travel** as trip collaborators
4. Use **Social** messaging for trip coordination

#### Phase 4: Plan Entertainment (Entertainment + Travel)
1. Open **Entertainment** and create a Watchlist for the trip
   - Add movie you'll watch Friday night at cabin (e.g., "Starry")
   - Add podcast recommendations for hiking
   - Add board games listed in Entertainment (e.g., Codenames, Ticket to Ride)
2. Download offline content for areas with limited connection
3. Link watchlist to trip in Travel

#### Phase 5: Prepare Home (Home Control)
1. Before leaving, open **Home Control**
2. Create a "Leaving for Weekend" routine:
   - Cameras to security mode
   - Thermostat to eco settings
   - Lights to occasional on (security)
3. On return: create a "Home" routine to reverse settings

### During the Trip

- **Travel**: Mark activities as done, add notes and photos to trip journal
- **Health**: Log daily mood and activity (morning hike, evening campfire atmosphere)
- **Social**: Share a moment with friends via post with photos
- **Entertainment**: Watch the movie Friday night, listen to podcasts

### After the Trip

1. **Travel**: Finalize trip, review photos, export trip summary with memories
2. **Finance**: Review all trip expenses; they're automatically categorized and totaled
3. **Social**: Post trip recap photo and trip narrative; get likes/comments from friends
4. **Health**: Review weekend's health metrics (activity level, mood progression)
5. **Companion Panel**: Notice all related items appear in "Recent" across universes; can skim trip context

### The Coherence

- **Data follows you**: Book a hotel → Payment linked to Finance → Confirmed in Travel together
- **Context persists**: Companion Panel shows "Travel (Relaxed)" + "Social (Collaborative)" throughout
- **One identity**: Friends see same trip details in Social and Travel universe views
- **Natural rhythm**: You never explicitly manage integrations; it just works

## Scenario 2: Build a New Skill and Share Your Journey

From "I want to learn" to "I'm a practitioner."

### The Journey

**Start**: Monday, you decide to learn UI/UX design  
**End**: Three months later, you have one portfolio piece, community feedback, daily habit, and credentials  
**Universes involved**: Learning → Create → Social → Communities → Productivity

### Step-by-Step Workflow

#### Phase 1: Enroll and Track Progress (Learning)
1. Open **Learning** and search for "UI/UX Design Fundamentals"
2. Enroll in the course
3. First lesson: core principles of user-centered design
4. Bookmark key concepts in Companion Panel
5. Set a learning signal: "Help me study, give me summaries"

#### Phase 2: Apply Learning (Create)
1. Open **Create** with your learning signal active
2. Start a new project: "Design Portfolio - Project 1"
3. Design a simple interface (based on course learnings)
4. Use version history to iterate as you learn
5. Add notes from course directly to design canvas via CP

#### Phase 3: Get Feedback (Social + Communities)
1. **Social**: Share progress post
   - "Week 1 of learning UX design. Here's my first interface mockup."
   - Tag: #learning #design #portfolio
   - Friends can react and comment
2. **Communities**: Join "UI/UX Designers" community
   - Post your design in feedback thread
   - Ask specific questions ("How can I improve the information hierarchy?")
   - Get constructive feedback from experienced designers
   - Incorporate feedback into design (back to Create)

#### Phase 4: Build Habit (Productivity)
1. Open **Productivity** and create a recurring task:
   - "Complete one UI/UX lesson"
   - Frequency: Daily (30 min)
   - Due time: 9am (focus signal recommended)
2. Track your daily streak
3. Create a milestone: "Complete 30-day design challenge"
4. Weekly review: reflect on progress, adjust difficulty

#### Phase 5: Credential and Share (Learning)
1. After completing course, open **Learning**
2. Receive certificate of completion
3. Export certificate as PDF or share link
4. Add to portfolio in **Create**
5. Create post in **Social**:
   - "Completed UI/UX Design Fundamentals! Here are my 3 projects"
   - Link to portfolio
   - Tag certificate

### Ongoing Workflow (Weeks 2-12)

#### Week 2: Deepen
- **Learning**: Take advanced interaction design module
- **Create**: Start project 2 with new skills
- **Communities**: Engage in weekly design critique
- **Productivity**: Add "Design practice" as additional task

#### Week 6: Accelerate
- **Learning**: Completed 6 courses; unlocked "Designer" badge
- **Create**: 2 portfolio pieces; both in version history
- **Social**: Share design thinking blog post; gets 100+ likes
- **Communities**: Other designers ask you to review their work (mentoring begins)

#### Week 12: Showcase
- **Create**: Export final portfolio as interactive PDF
- **Social**: Final post: "3-month journey from novice to first client project"
- **Learning**: Export transcript showing all courses completed with scores
- **Communities**: Offer to mentor new designers (giving back)

### The Coherence

- **One consistent learner**: Your design files, course progress, community reputation, and daily habit are all "you"
- **Progress is visible everywhere**: Companion Panel shows learning milestone reached, which updates your profile, which updates social presence
- **Feedback loop**: Course → Create → Communities feedback → back to Create → Social sharing → more engagement
- **Natural motivation**: Seeing your habit, your work, and community recognition across universes reinforces commitment

## Scenario 3: Master Your Daily Rhythm

Morning clarity → afternoon flow → evening reflection.

### The Journey

**Timeline**: One week of intentional daily living  
**Universes involved**: Home → Productivity → Learning/Entertainment → Health → Social

### Morning Routine (6:00 - 8:00 am)

#### Phase 1: Wake Up (Home)
1. Alarm goes off at 6:00 am
2. Open **Home** dashboard
3. Morning routine auto-activates:
   - Lights gradually brighten
   - Coffee maker turns on
   - Thermostat set to 72°F
   - News briefing starts on speakers (from Entertainment)
4. Companion Panel set to "Home" tone (oriented, calm)

#### Phase 2: Priorities (Productivity)
1. Open **Productivity** while having breakfast
2. Review today's tasks (already prioritized from yesterday's plan)
3. Top 3 for today identified
4. Time-block them: 10-12 (Focus Project), 2-3 (Meetings), 4-5 (Admin)
5. Companion Panel now shows "Productivity (Focus)"

#### Phase 3: Wellness (Health + Learning)
1. Log breakfast and mood in **Health**
2. Open **Learning** for quick 10-minute bite-sized lesson
   - "Daily Spanish: 5 new phrases"
   - Take notes in Companion Panel
3. Mark lesson complete
4. Return to **Health**: log learning as cognitive activity

### Afternoon Workflow (9:00 am - 5:00 pm)

#### Phase 1: Deep Work (Productivity + Create)
1. Time-block active: **Productivity** switches to "Focus" signal
2. All notifications muted except critical
3. Open **Create** or work on focus project
4. Companion Panel shows "Focused" – minimal UI, full canvas
5. Productivity timer runs; breaks scheduled every 90 minutes

#### Phase 2: Break and Social (Social + Health)
1. 90-minute timer dings
2. 15-minute break: open **Social**
3. Quick scroll through friends' updates
4. Post a moment: "Lunch break. That UI problem is finally solved!"
5. Return to work after break
6. **Health**: Log work activity and social break

#### Phase 3: Meetings (Productivity + Communities)
1. Meetings block (2-3 pm): Productivity reminder  
2. Open **Communities** for team discussion channel
3. Share project update, receive feedback
4. Make notes to address after meetings

### Evening Routine (5:00 - 10:00 pm)

#### Phase 1: Wrap-up (Productivity + Social)
1. Open **Productivity**: Mark today's tasks complete/incomplete
2. Plan tomorrow: drag undone tasks forward, add new ones
3. Weekly review prompt appears (Friday) – click to review week
4. Open **Social**: react to friend posts, catch up on group chat
5. Companion Panel transitions to "Evening" tone (mellow, reflective)

#### Phase 2: Learning and Growth (Learning + Entertainment)
1. Open **Learning**: Evening learning goal – 20 minutes
2. Pick a learning interest unrelated to work (e.g., photography basics)
3. Complete one lesson
4. After learning, open **Entertainment**
5. Watch one episode of a show you're working through (30 minutes)
6. Set down devices at 9 pm

#### Phase 3: Reflection (Health)
1. Open **Health** and evening check-in:
   - Log mood (today's trajectory)
   - Log sleep readiness (calm, focused, energized?)
   - Log energy level
2. Optional: open **Meditation** app inside **Health** for 10 minutes
3. Set sleep goal for tonight: 8 hours
4. Close Companion Panel

#### Phase 4: Prepare Home (Home Control)
1. Open **Home Control**
2. Activate "Good Night" routine:
   - Lights fade to 10% over 30 minutes
   - Thermostat drops to 68°F
   - Doors lock confirmed
   - Security cameras on

### Weekly Rhythm

**Monday - Thursday**: Repeat daily routine with variations (different learning, different work)

**Friday Evening**:
1. Open **Productivity**: Full weekly review
   - Tasks completed: 85%
   - Habits kept: 6/7 days (missed Wednesday yoga)
   - Wins: Solved the UI problem, gave great presentation, learned 5 photography concepts
2. Open **Health**: View week's dashboard
   - Sleep: average 7.5 hours
   - Mood progression: stronger on days with learning + social connection
   - Activity: consistent with morning routine benefits
3. Open **Social**: Post weekly recap
   - "Week wrap: Hit my learning goals, shipped the project, actually felt calm"
   - Friends respond, validate your effort
4. Open **Learning**: Check weekly streak badge (maintained!)

**Weekend**:
- Lighter routine (no time-blocking)
- Focus on leisure, family, reset
- One trip, one hobby, one community engagement planned in next week

### The Coherence

- **One timeline**: Morning through evening is one coherent "self" across all universes
- **Context awareness**: Signals (Focus, Evening, Social) adjust which universes take center stage
- **Data and mood together**: Health tracks physical wellness and emotional state, which correlates with productivity and learning success
- **Rhythm reinforces rhythm**: Daily routine makes weekly review easier; weekly insights improve next week's daily rhythm
- **Tools fade away**: After a week, you're not aware of switching between universes; it's just "your day"

## Scenario 4: Launch a Team Project with Brand Alignment

From brainstorm to shipped with team coordination and brand consistency.

### The Journey

**Duration**: 6-week project  
**Universes involved**: Create → Productivity → Social → Communities → Brand → Finance

### Week 1: Kickoff

#### Phase 1: Align on Brand (Brand + Communities)
1. **Brand**: Open brand overview for your team
2. Review: voice guidelines ("playful but professional"), color palette, typographic scale
3. **Communities**: Create private team space for "Q1 Website Redesign"
4. Pin brand guidelines in pinned announcements
5. Companion Panel set to "Brand-aligned" (helps reviewers catch deviations)

#### Phase 2: Plan Scope (Productivity + Create)
1. **Productivity**: Create project "Q1 Website Redesign"
2. Break into milestones:
   - Week 1-2: Discovery + wireframes (Milestone: Discovery Done)
   - Week 3-4: Design system + components (Milestone: Design System)
   - Week 5: Integration and refinement (Milestone: QA Ready)
   - Week 6: Launch (Milestone: Live)
3. Assign tasks to team members
4. **Create**: Create shared project space for designs
5. Invite team: 2 designers, 1 developer, 1 product manager

#### Phase 3: Gather Requirements (Communities + Productivity)
1. **Communities**: Create initial brainstorm thread
2. Each team member posts what they think the redesign should accomplish
3. Vote on top priorities (4 voting options)
4. Top 2 emerge: "Mobile-first experience" and "Faster load time"
5. **Productivity**: Add these as project constraints in milestone descriptions

### Weeks 2-4: Design Phase

#### Phase 1: Design and Iterate (Create + Brand)
1. **Create**: Designer 1 opens project
2. Creates wireframes for homepage, product pages, blog
3. Companion Panel: Brand tone is active, suggesting color palette and typography
4. Uses version history: Draft 1 → Draft 2 (feedback incorporated) → Draft 3 (design system applied)
5. **Brand**: Cross-reference with design system
   - Does this use approved colors?
   - Are button styles consistent with brand?
   - Is typography hierarchical per brand guidelines?
6. Create: Designer exports PDF for review

#### Phase 2: Gather Feedback (Communities + Social)
1. **Communities**: Post design PDF in team channel
2. Tag team for review: "Design Review – Homepage + Product Pages"
3. Developers ask: "Can we simplify the product filter for faster loads?"
4. PM asks: "Is this mobile-responsive?"
5. Designer responds inline: "Yes, fully mobile. Filters revised in v2."
6. **Social**: Designer shares update with broader cross-functional team:
   - "Design review complete, incorporating feedback"
   - Friends/colleagues react, add encouragement
7. Designer iterates (back to Create)

#### Phase 3: Track Progress (Productivity)
1. **Productivity**: Designer marks "Wireframes complete" and "Design System applied"
2. Milestone 1 completion: 80% (waiting on one outstanding feedback item)
3. Team can see progress in project view
4. Weekly sync in **Communities**: Team publishes progress update
   - Design: 80% done
   - Dev prep: 50% done
   - Ready for next phase by end of week

### Weeks 5-6: Finalization and Launch

#### Phase 1: Integration (Create + Productivity)
1. **Create**: Developer now works in same shared project
2. Takes final design files
3. Implements in code with design system tokens
4. Uses version history to track integration progress
5. Tags designer for design QA on implementation

#### Phase 2: Final Coordination (Communities + Productivity + Brand)
1. **Communities**: Daily standup thread
   - Dev: "CSS Grid layout done, working on responsiveness"
   - Designer: "QA'ing implementation, looks great"
   - PM: "Copy and imagery ready"
2. **Productivity**: Final tasks tracked to completion
3. **Brand**: Final brand QA checklist completed
   - ✅ Colors match palette
   - ✅ Typography hierarchy correct
   - ✅ Logo placement optimized
   - ✅ Tone in copy matches voice guidelines
4. Go-live checklist: All items checked

#### Phase 3: Launch and Celebrate (Social + Communities + Finance)
1. **Productivity**: Mark entire project complete
2. **Communities**: Launch announcement posted
3. **Social**: Team posts launch across social:
   - "After 6 weeks, our new website is live! Huge thanks to the team."
   - Links to new site
   - Friends celebrate in comments
4. **Finance** (optional): Project budget tracked; actual costs vs. estimated
   - Designer hours: logged
   - Developer hours: logged
   - Tools/resources: categorized

### The Coherence

- **Single source of truth**: Designs are in Create, progress in Productivity, alignment in Brand, all discussed in Communities
- **No duplicate effort**: Changes made in Create are automatically referenced in Productivity ("Design QA complete")
- **Asynchronous by default**: Team doesn't need all meetings; Communities thread replaces many sync calls
- **Accountability visible**: Everyone sees brand checklist, progress tracker, and community updates
- **Celebration built-in**: Normal workflow includes milestone completion and social sharing of wins

## Multi-Universe Principles

### 1. Start with Intent, End in Perspective
Every multi-universe workflow begins in one universe and flows through others because that's the natural sequence of real work:
- Travel (planning) → Finance (budgeting) → Social (sharing) → Entertainment (memories)
- Learning (growth) → Create (practice) → Communities (feedback) → Productivity (habit)

### 2. Companion Panel is Your Hub
The CP shows you task/context across all universes:
- "Travel" signal: Trip details appear everywhere you look
- "Social" scope: Friends' reactions show up in Create and Learning
- "Productivity" tone: Deadlines and blockers emphasized in all views

### 3. Data Follows the Thread
When you create a calendar event in Travel, it:
- Appears in Productivity as a time-block
- Creates Finance transaction for lodging
- Becomes a Social item to share
- Shows up in Health as "travel week" context

No manual syncing. Data moves intelligently based on relationships.

### 4. Signals Orchestrate Experience
A single signal (Focus, Relaxed, Social) changes the UI and emphasis across all universes you're in:
- **Focus**: Entertainment goes quiet, Productivity front-and-center, Create fullscreen
- **Social**: Social feed center stage, Create ready for sharing, Communities prominent
- **Relaxed**: Health suggestions appear, Entertainment prioritized, Productivity dimmed

### 5. Time Blocks Shape Workflows
Morning → Afternoon → Evening sequences use different universes naturally:
- Morning (Home → Productivity → Health): You wake, plan, reflect
- Afternoon (Productivity → Create → Communities): You work, share, get feedback
- Evening (Health → Entertainment → Home): You wind down, enjoy, rest

---

## Tips for Creating Your Own Multi-Universe Workflows

1. **Start with a goal**, not a universe ("I want to master photography" not "Open Learning")
2. **Notice the natural sequence** (Learn → Practice → Share → Reflect)
3. **Use Companion Panel** to signal your intent to Aurora
4. **Let data flow** – don't manually move things between universes
5. **Review weekly** using Productivity to see which multi-universe workflows you actually use
6. **Iterate**: If a workflow doesn't feel natural, adjust the sequence or the universes involved
7. **Share templates**: When you've found a workflow that works, save it and share with friends/team

---

**The deeper principle:** Aurora isn't 15 separate apps. It's one coherent platform where your life flows naturally from planning to creation to sharing to reflection. These multi-universe workflows show what that feels like in practice.
