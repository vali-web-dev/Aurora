# Advanced Usage and Signals

Signals let you shape Aurora in real time by overriding default tone and scope.

## Signal Deep Dive
- Focus: Strategist tone, light scope, minimal distractions
- Crisis: Guardian tone, deep scope, safety-first UI
- Exploration: Explorer tone, standard scope, discovery-first UI
- Collaboration: Strategist tone, shared tools
- Relaxation: Mentor tone, minimal scope

## Signal Combinations
- Focus + Learning: quiet UI with step-by-step guidance
- Exploration + Create: more templates and inspiration
- Reflection + Finance: trend summaries and insights

## Common Workflows

### Morning Routine
1. Home summary
2. Productivity goals
3. Social check-in
4. Productivity focus session
5. Learning break

### Creative Flow
1. Create universe
2. Exploration signal
3. Work session
4. Review and publish or archive

### Learning Sprint
1. Learning universe
2. Learning signal
3. Notes in Companion Panel
4. Apply in Create

### Evening Wind-Down
1. Relaxation signal
2. Home review
3. Journal in Create or Health
4. Entertainment and rest

## Extensions and Integrations (User View)
- Export data to common formats
- Optional sync across devices
- Connect external services through Automation (if enabled)

## Power Tips
- Use global search to jump across universes quickly
- Use the Companion Panel for fast context switches
- Review weekly summaries to spot patterns

## Advanced Navigation
- Use the Aurora logo menu to jump universes without backtracking
- Combine search with signals (e.g., set Focus, then search “review”)
- Use keyboard shortcuts for universe switches

## Automation Entry Points
- Start in Automation universe with a single trigger
- Add one action (create task, send summary)
- Test the workflow before turning it on
- See [/docs/aurora-book/end-user/automation-guides](/docs/aurora-book/end-user/automation-guides)
