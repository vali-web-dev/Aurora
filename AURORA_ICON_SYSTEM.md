# Aurora Icon System - Complete Architecture

## Overview
This document defines the complete, organized, and intentional icon system for Aurora's digital civilization platform. Every universe, sub-universe, page, and feature has a dedicated, semantically appropriate icon.

## Icon Design Principles
1. **Semantic Clarity**: Icons visually represent their function
2. **Consistent Style**: All icons use 24x24 viewBox with 2px stroke weight
3. **Accessibility**: Icons include proper color coding and ARIA support
4. **Scalability**: Vector-based SVG for all resolutions
5. **Organization**: Grouped by universe hierarchy (Primary > Explore > Support)
